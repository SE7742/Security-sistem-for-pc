# Logs / Günlük Dosyaları

Bu klasör sistem log dosyalarını içerir.

## İçerik

- Sistem başlangıç logları
- Tespit kayıtları
- Hata günlükleri
- Aktivite kayıtları

## Önemli

⚠️ **Gizlilik Uyarısı**: Bu klasördeki log dosyaları `.gitignore` tarafından Git'e yüklenmez.
Kişisel verileriniz ve aktivite kayıtlarınız GitHub'a gönderilmez.

## Otomatik Temizlik

Eski log dosyaları `AUTO_CLEANUP_DAYS` ayarına göre otomatik olarak silinir.
Varsayılan: 7 gün
