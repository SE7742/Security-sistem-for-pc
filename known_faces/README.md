# Known Faces / Tanınan Yüzler

Bu klasör yüz tanıma sistemi için kayıtlı kişilerin fotoğraflarını içerir.

## Kullanım

1. Tanınmasını istediğiniz kişilerin fotoğraflarını bu klasöre ekleyin
2. Dosya adı olarak kişinin ismini kullanın (örn: `ahmet.jpg`, `ayse_yilmaz.png`)
3. Desteklenen formatlar: `.jpg`, `.jpeg`, `.png`

## Önemli

⚠️ **Gizlilik Uyarısı**: Bu klasördeki fotoğraflar `.gitignore` tarafından Git'e yüklenmez.
Kişisel fotoğraflarınız GitHub'a gönderilmez.

## Örnek Yapı

```
known_faces/
├── README.md
├── ahmet.jpg
├── ayse.png
└── mehmet_yilmaz.jpeg
```
